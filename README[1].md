# Raghav Agrawal — Personal Portfolio

A modern, premium personal portfolio website built with **React + Vite + Tailwind CSS**.

## 🚀 Live Demo

> Deployed at: [raghav-cse-dev.github.io/raghav-portfolio](https://raghav-cse-dev.github.io/raghav-portfolio/)

## ✨ Features

- 🎨 **Dark premium design** — blue/purple/pink gradient theme
- 💫 **Animated hero** — typing effect, floating orbs, parallax icons
- 📱 **Fully responsive** — mobile hamburger menu, adaptive layouts
- 🔍 **Smart navbar** — active section tracking, smooth scroll
- 🎯 **Filterable skills** — tab-based skill category filters
- 🃏 **Glass morphism cards** — modern frosted glass design
- 📜 **Scroll animations** — fade-in sections via Intersection Observer
- ✉️ **Contact form** — opens mail client pre-filled
- ⚡ **Fast loading** — Vite + optimized bundle (~200KB JS)

## 🗂️ Sections

1. **Hero** — Name, role typing animation, CTA buttons, social links
2. **About** — Story, interests, quick facts
3. **Education** — JECRC University B.Tech card with progress
4. **Skills** — 10 skills with progress bars and filter tabs
5. **Projects** — 3 project cards with tech stacks
6. **Achievements** — Ready-to-fill categories
7. **Contact** — Form + contact links + footer

## 🛠️ Tech Stack

- **React 18** — UI components
- **Vite 5** — Build tool & dev server
- **Tailwind CSS 3** — Utility-first styling
- **Lucide React** — Icon library
- **PostCSS + Autoprefixer** — CSS processing

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deploy to Vercel

1. Push to GitHub
2. Import project on [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite — just click Deploy!

## 📝 Customization

- **Add achievements**: Edit `src/components/Achievements.jsx`
- **Update projects**: Edit `src/components/Projects.jsx`
- **Add skills**: Edit `src/components/Skills.jsx`
- **Change colors**: Edit `tailwind.config.js`
